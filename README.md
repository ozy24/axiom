# Axiom

A Quake II Rerelease multiplayer mod: clean core gametypes (FFA, TDM, CTF, Duel),
streamlined match handling, and a solid base for other mods to build on. It is a
drop-in `game_x64.dll`; single player and the mission packs keep working as stock.

**Status:** early foundation work. Nothing playable beyond stock yet; see
`STATUS.md`.

- Contributors (and AI sessions): start with `AGENTS.md`.
- Settled design questions: `docs/decisions/`.
